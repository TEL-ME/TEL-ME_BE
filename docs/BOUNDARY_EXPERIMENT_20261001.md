## 재현 조건과 원시 기록

13.1절의 90건 측정과 같은 서버 설정·모델·DB를 사용했다. 재임베딩 및 임계값 변경은 없다.
직전 90건 측정 후 확인된 Q_A 벡터 집계 MD5 `4c6faa4addd8f37e5e7b5921f0882207`, 질문 벡터 `2343d78abdb1daa5b22062a3e574a971`.
이번 16건 수집 직후 DB가 종료돼 지문 대조를 보류했으나, DB 재기동 후 확인을 완료했다. `policy_ref NOT LIKE 'POLICY-%'` 조건의 Q_A·질문 벡터가 각각 1,150건이고 두 지문 모두 위 측정 전 값과 일치한다. 임시 서버 프로세스는 종료된 상태다.

**시드와 집계 범위:** 위 지문 조건은 검색 쿼리의 시드 제외 조건이 아니다. 저장된 90건·16건의 Q_A/질문 원시 결과 4개에는 `slot_id=null` 결과가 없고, 측정·집계에서 별도로 시드를 제외하지 않았다. 사후 재확인한 현재 DB는 전체 FAQ 1,150건, `POLICY-*` 시드 0건, `slot_id=null` FAQ 0건이다. 현재 상태만으로 과거 측정 당시 전체 행 수를 증명하지는 않는다. 시드가 포함된 환경에서는 검색 결과가 달라질 수 있으므로 재현 시 데이터 구성을 맞춰야 한다.
모델은 bge-m3:latest(F16, 1024차원), digest `7907646426070047a77226ac3e684fbbe8410524f7b4a74d02837e43f2146bab`.
포트 18090, `faq.search-test-api-enabled=true`, `search.similarity-threshold=0`, `search.dual-vector.question-threshold=0`인 임시 서버에서 수집했다.

```bash
python3 scripts/check_eval_questions.py scripts/data/eval_questions_boundary_experiment_16.json --faq scripts/data/faq_full_1150.json
python3 scripts/measure_search_quality.py scripts/data/eval_questions_boundary_experiment_16.json --api-url http://localhost:18090/api/v1/faq/search --vector QUESTION --top-k 3 --timeout 150 --dump-json .measure/boundary16-question-20261001.json
python3 scripts/measure_search_quality.py scripts/data/eval_questions_boundary_experiment_16.json --api-url http://localhost:18090/api/v1/faq/search --vector QA --top-k 3 --timeout 150 --dump-json .measure/boundary16-qa-20261001.json
```

겹침 검사는 remote `ac6cf68`의 `scripts/check_eval_overlap.py`를 임시 파일로 읽어 기존 130·보강 50·고정 90건을 `--against`로 지정했다. 이후 원격 변경을 통합해 같은 스크립트를 레포에 포함했다. 아래 명령으로 재현할 수 있다.

```bash
python3 scripts/check_eval_overlap.py scripts/data/eval_questions_boundary_experiment_16.json --against scripts/data/eval_questions_130.json scripts/data/eval_questions_supplement_50.json scripts/data/eval_questions_holdout_90.json
```

로컬 `.measure`(커밋 제외)에 초안20, 입력 스냅샷, 두 벡터 원시 결과, top-3 FAQ 본문을 포함한 요약 JSON을 보존했다.
이 문서의 비율은 정답 라벨이 모두 UNRELATED라는 현재 검토를 전제로 한다. 실제 DUAL 순위·지연이나 답변 생성 품질은 이번 범위가 아니다.
