# 검색 임계값 0.6과 답변 품질 개선 검토

## 목적

검색 임계값을 현재 0.72에서 0.6으로 낮추면 정답 근거를 더 많이 전달할 수 있는지, 늘어난 후보를 근거 적합성 판정과 답변 가드로 안전하게 처리할 수 있는지 검토한다.

## 측정 근거

### 검색 임계값 0.72와 0.6

| 구성 | 같은 정책 근거 전달 (80개) | 근거 없음 (80개) | 답 없는 질문 통과 (50개) | 어려운 인접 질문 통과 (10개) |
| --- | ---: | ---: | ---: | ---: |
| 현재 develop, 임계값 0.72 | 37 | 43 | 3 | 미측정 |
| 벡터 상위 3개, 임계값 0.6 + EXAONE 판정 | **69** | **10** | 7 | 3 |
| 벡터 상위 3개, 임계값 0.0 + EXAONE 판정 | 71 | 8 | 9 | 3 |
| 리랭커 + EXAONE 판정 | 72 | 6 | 7 | 3 |
| 리랭커 + Qwen3 14B 판정 | 76 | 2 | 1 | 0 |

이 평가는 130개 질문(답변 가능 80, 답변 불가 50)과 1,150개 FAQ를 사용했다. "같은 정책"에는 평가셋의 정답 FAQ와 같은 정책을 설명하는 FAQ도 포함한다. 임계값 0.6 구성은 리랭커 없이 벡터 검색 상위 3개를 EXAONE 판정기에 전달했다. 판정 프롬프트는 기존 "애매하면 true"를 "애매하면 false"로 바꾼 STRICT 변형이다.

이 구성에서 현재 develop 대비 답변 가능한 질문의 같은 정책 근거 전달은 37건에서 69건으로 늘었다. 답변 불가 질문의 통과도 3건에서 7건으로 늘었다. 즉 0.6만 낮춘 것이 아니라, 검색 기준 완화와 보수적인 근거 판정을 함께 적용했을 때의 결과다. 이 측정은 후속 답변 생성, Answer Guard, SSE까지 포함한 전체 응답 품질 결과는 아니다.

### 근거 적합성 판정기

기존 판정 실험은 리랭커 상위 3개 후보를 사용했다. 원래 develop 프롬프트의 "애매하면 true" 설정에서 EXAONE 3.5 7.8B는 답변 가능한 후보 60건 중 59건을 통과시켰지만, 답변 불가인 인접 질문 24건 중 12건과 어려운 인접 질문 10건 중 7건도 통과시켰다. 통신과 무관한 질문 16건은 통과시키지 않았다.

후속 0.6 실험에서는 판정 프롬프트를 "애매하면 false"로 바꾸었다. 벡터 검색 상위 3개 구성에서 같은 정책 근거 전달은 69/80, 답변 불가 질문 통과는 7/50이었다. 따라서 EXAONE에 이 지침을 적용한 결과는 측정되어 있다. 다만 같은 프롬프트를 리랭커 구성에도 적용한 결과와 서로 다른 구성을 단순 비교하면 안 된다.

별도 리랭커 구성에서 Qwen3 14B 판정은 어려운 인접 질문 0/10, 인접 질문 1/24, 무관 질문 0/16을 통과시켰다. 다만 다른 모델과 후보 구성의 결과이므로 EXAONE 구성과 직접 등치할 수 없다.

### 프롬프트와 답변 가드

별도의 답변 품질 보고서에서는 답변 프롬프트와 가드를 단계별로 바꿔 150개 질문을 평가했다. 해당 실험의 최종 단계에서 문장 환각률은 기준선 20.2%에서 10.8%로 줄었다. 이 결과는 프롬프트와 가드가 답변 문장의 근거성을 개선할 수 있다는 근거다.

이 환각률 결과는 검색 임계값 0.6 및 EXAONE 근거 적합성 판정과 결합한 평가가 아니다. 따라서 0.6 검색 + 보수적 판정으로 근거를 고른 뒤 답변 프롬프트와 Answer Guard까지 적용했을 때의 최종 환각률은 아직 확인되지 않았다.

## 해석과 제안

검색 임계값 0.6은 정답 근거 후보를 늘리는 용도로 시험할 수 있다. 다만 검색 점수는 질문과 FAQ가 비슷한지를 나타낼 뿐, 그 FAQ가 실제 질문에 답하는지를 보장하지 않는다. 다음 단계를 함께 검증해야 한다.

1. 클로드 측정에서 효과가 확인된 원문 검색과 임계값 0.6 + EXAONE STRICT 판정을 같은 평가 질문으로 재현한다.
2. 판정 결과가 불확실하면 답변 불가로 처리하고, 통과한 근거만 답변 생성에 넘긴다.
3. 생성된 답변에는 근거 제한 프롬프트와 Answer Guard를 적용해 금액, 기간, 혜택, 조건 등 근거 밖 내용을 차단한다.
4. 전체 파이프라인에서 정답 정책 근거 전달, 답변 불가 질문 통과, 최종 환각률, 응답 지연시간을 함께 비교한다.

현재 결과는 다음 실험을 진행할 근거로 충분하다. 다만 평가가 130개 고정 질문에 한정되고 답변 생성과 Answer Guard까지 결합한 최종 결과는 없으므로, 0.6을 운영 임계값으로 확정하기 전 전체 파이프라인 회귀 평가가 필요하다.
