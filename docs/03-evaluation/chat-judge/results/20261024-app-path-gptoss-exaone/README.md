# 앱 경로 답변 품질: gpt-oss vs 모든 단계 EXAONE (TELME-237)

실제 채팅 앱 경로(문맥 → 라우팅 → 검색·근거 판정 → 되묻기·생성 → 답변 검사)로 서비스 품질셋과 흐름셋의 답을 만들고, Judge 3종과 검토로 판정했다. 운영 경로(gpt-oss)와, 같은 앱에서 모든 LLM 호출을 EXAONE으로 바꾼 경로를 비교한다.

## 판단

- **운영 경로(gpt-oss)의 품질셋 통과율은 78.5%(241/307)다.** 모든 단계를 EXAONE으로 바꾸면 39.4%(121/307)다.
- 흐름셋(되묻기·회원 데이터·매장 대화 93턴)은 gpt-oss 69.9%(65/93), EXAONE 49.5%(46/93)다.
- 차이가 큰 묶음은 단일 질문(93/120 대 36/120), 복합 질문(26/40 대 7/40), 멀티턴(31/40 대 14/40)이다. 범위 밖 질문은 둘 다 거의 통과한다(19/19, 18/19).
- [답변 생성 비교](../20261018-answer-generation/README.md)의 73~74%는 정답 근거를 고정하고 생성 단계만 잰 값이다. 이 문서의 값은 검색·라우팅까지 포함한 앱 전체 경로 값이라 서로 바꿔 쓰지 않는다.

## 판정 절차

1. **Judge 3종 결합**: 세 모델이 모두 통과면 통과, 세 모델이 모두 실패면 실패로 확정했다.
2. **갈린 턴 검토**: 모델끼리 판정이 갈렸거나 미확정으로 남은 216턴(gpt-oss 품질 88, 흐름 21 / EXAONE 품질 91, 흐름 16)은 사람이 근거 FAQ와 답을 대조해 직접 판정했다.
3. **판정 기준 결정**: 평가셋 라벨과 앱 설계가 충돌한 25턴은 팀이 정한 아래 기준으로 판정했다.

| 번호 | 기준 | 적용 턴 |
|---|---|---|
| 1 | 지역 없이 묻는 매장 영업시간은 지역 되묻기도 정답으로 본다. 지역을 알아도 답이 없는 질문(점심시간)과 매장 방문 문장은 해당하지 않는다 | C015, M014, A079 |

## 한계

- 모델마다 캡처 1회, 판정 모델마다 1회(미확정 턴만 재판정)다. 회차에 따른 흔들림 범위는 없다.
- 갈린 턴은 한 사람이 판정했다.
- EXAONE 회차는 회색 구간 근거 판정과 #215 원문 재검색이 꺼진 상태다. EXAONE 모델만의 차이가 아니라 운영 장애 때 EXAONE으로 모두 넘어간 경로의 결과로 읽는다.
- **EXAONE 실행 시간은 배포 환경이 아니라 이 PC(RTX 5070 Ti, Docker Ollama)에서 잰 값이다.** 배포 GPU 서버(vLLM)와 다르므로 시간 비교에 쓰지 않는다. 이 문서는 정확도만 비교한다.
- 평가셋은 이전 채점(10-21) 뒤 #197에서 바뀌었다(흐름셋 대본 보강, 품질셋 매장 되묻기 답 1개). 이전 채점 수치와 바로 비교하지 않는다.
- 판정 호출 69건이 출력 형식 오류로 실패했다(Mistral 49, Qwen 10, DeepSeek 10). 재판정 뒤에도 Mistral만 빈 턴이 남은 경우는 검토 대상에 들어갔다.
- 고정 평가 문장으로 잰 값이며 실제 고객 대화의 분포가 아니다.

## 원시 파일과 다시 집계

`raw.tar.xz`를 풀면 회차별 폴더(`gpt-quality`, `gpt-flows`, `exa-quality`, `exa-flows`)와 `review/`가 나온다.

| 파일 | 내용 |
|---|---|
| `<회차>/capture.json` | 턴별 실행 단계 기록, 라우팅, 검색 결과, 근거 판정, LLM 호출 기록, gpt-oss 호출 원문과 토큰(`bedrockCalls`), 최종 답, 저장된 근거 |
| `<회차>/ollama-calls.jsonl` | EXAONE·bge-m3 호출마다 요청 본문, 응답 원문, 토큰 수, 시간(기록 프록시 경유) |
| `<회차>/manifest.json`, `env.txt` | 캡처 설정, 평가셋 해시, 앱 환경 변수 |
| `<회차>/qwen.json`, `deepseek.json`, `mistral.json` | 모델별 판정(r3 재판정까지 반영) |
| `<회차>/combined.json`, `combined-majority.json` | any-fail, 다수결 결합 |
| `review/review-first-pass.json` | 갈린 턴의 1차 판정과 축별 판단·이유 |
| `review/review-final.json`, `review-final.tsv` | 갈린 216턴의 1차·최종 판정, 적용한 판정 기준, 검토 메모 |

```powershell
mkdir .measure/j1024
tar -xf docs/03-evaluation/chat-judge/results/20261024-app-path-gptoss-exaone/raw.tar.xz -C .measure/j1024
python -X utf8 -m scripts.chat_judge.combine_judges .measure/j1024/gpt-quality/qwen.json .measure/j1024/gpt-quality/deepseek.json .measure/j1024/gpt-quality/mistral.json --capture .measure/j1024/gpt-quality/capture.json --out .measure/j1024/gpt-quality-combined.json
# 최종 통과 = combined.json에서 pass가 true인 턴 + review/review-final.tsv에서 그 회차의 최종이 PASS인 턴
```
