# 2026-10-17 FAQ 질문 문장을 상황 맥락으로 넘기는 시험(되돌림)

Judge는 FAQ 질문 문장을 정책 근거로 쓰지 않도록 FAQ 답변 본문만 받는다. 그래서 답 문장만으로는 어떤 상황에 대한 답인지 모호한 FAQ에서 틀린다. 예를 들어 U041 "이번 달 요금이 많이 나와서 두세 번에 나눠 내도 돼요?"에, 해지할 때 단말 할부금에 대한 FAQ(TERMINATE-0115, 질문 "요금 부담돼서 해지하는데 할부 한 번에 내는 게 나아요", 답 "원칙은 한 번에 내는 겁니다. 부담되시면 계속 나눠 내는 것도 됩니다")를 근거로 읽고 앱의 적절한 거절을 과도한 거절로 판정했다.

FAQ 질문 문장을 "이 답이 어떤 상황에 대한 것인지"만 알려 주는 `situation`으로 넘기고, 판정 기준에 "상황은 근거가 아니다, 다른 상황의 답이면 근거가 아니다"를 넣어 시험했다. **결과가 나빠지거나 같아서 되돌렸다.** 지금 판정 프롬프트는 시험 전과 글자 단위로 같다.

## 결과

Judge 검증셋 116건(판정자 A 기준). 세 경우 모두 지금 코드 규칙으로 다시 집계했다. "시험 전"은 [후보 비교](../20261016-judge-candidates/README.md)의 필수 사실 붙인 실행이다.

- **두 판정 모두에 넣으면 나빠졌다.** 근거성에서 근거 없음 → 근거 있음으로 바뀐 판정이 Mistral 11건, DeepSeek 9건, Qwen 3건이었다. 예: PIPE-BILLING-0074 "미납이 있어도 소액결제 한도를 올릴 수 있어요?"에서 FAQ 답은 "한도 상향은 본인 인증으로… 미납 여부와 관련된 제한은 고객센터에서 확인해 주세요"뿐인데, Mistral은 판정 이유에 "situation에서도 '미납이 있어도 … 올릴 수 있어요?'라는 질문에 대해…"라고 적고 앱 답 "미납이 있더라도 올릴 수 있습니다"를 근거 있음으로 봤다. 상황 문장을 근거로 쓴 것이다. 검증셋 질문은 TELME-100 때 FAQ 질문 문장을 그대로 쓴 것이라 상황 문장이 고객 질문과 같아서 더 심했다. 근거성 판정은 근거 ID만 내고 인용문이 없어 코드 검사로 막지 못한다.
- **근거 충분성 판정에만 넣으면 비슷했지만 이득이 없었다.** 사람이 과도한 거절로 본 7건을 잡는 수는 같았고(Qwen 7, DeepSeek 6, Mistral 5→6), 적절한 거절을 과도한 거절로 본 경우가 0→1건(Qwen)이었다. 검증셋에는 U041 같은 사례가 없어, 서비스 품질셋의 U041·U021·U028·U037 네 턴을 따로 돌렸다. **U041은 세 모델 모두 그대로 "근거 충분 → 과도한 거절"이었다.** 상황 문장이 요청에 들어갔는데도 DeepSeek는 "할부를 나눠 내는 것도 된다"를 이번 달 요금 분할의 근거로 인용했다.
- 같은 프롬프트로 다시 돌린 근거성 축도 모델에 따라 4~11건 바뀌었다(DeepSeek 98→94, Mistral 89→78). 단일 실행의 몇 건 차이는 판단 근거가 아니다.

비용은 Judge 검증셋 두 번 $1.84, U041 네 턴 $0.02다.

## 남은 것

U041(맥락을 몰라 과도한 거절)과 U021(뜻을 뒤집은 답을 근거 있음)은 Judge가 틀리는 알려진 사례로 Judge 검증셋 v2에 넣는다. 고치려면 프롬프트에 맥락을 더 주는 것보다 근거성 판정에도 근거 인용문을 받아 원문 대조하는 쪽을 먼저 본다.

## 파일

`raw.tar.xz`에 `both-stages/`, `evidence-only/`(Judge 검증셋 모델별 판정), `u041-evidence-only/`(서비스 품질셋 네 턴의 캡처와 판정), `validation-capture.json`(검증셋을 캡처 형식으로 바꾼 것)이 있다.

```powershell
mkdir .measure/situation-context
tar -xf docs/03-evaluation/chat-judge/results/20261017-situation-context/raw.tar.xz -C .measure/situation-context
python -X utf8 -m scripts.chat_judge.combine_judges .measure/situation-context/evidence-only/qwen.json .measure/situation-context/evidence-only/deepseek-v3.2-usw2.json .measure/situation-context/evidence-only/mistral-large-3.json --validation --capture .measure/situation-context/validation-capture.json
```
