## 확인할 원문

**실제 채팅 `NO_EVIDENCE`**

- 질문: 유심 재발급하면 택배비는 따로 내나요?
- 답변: 유심 재발급 비용은 7,700원으로 포함되어 있습니다.
- 검색 FAQ: “유심 재발급 비용이 얼마예요?” → “7,700원입니다. 매장에서 바로 받으실 수 있고, 온라인 신청 시 택배로 2~3 영업일 걸립니다.” 검색된 다른 두 FAQ도 배송 기간과 재발급 비용만 언급한다.

**합성 `USIM-0072`**

- 질문: 유심 깨졌는데 신고해야 하나요
- 답변: 깨진 건 신고 안 하셔도 됩니다. 새로 받으시면 예전 건 자동으로 없어집니다. 유심 재발급 시 로밍 데이터 50GB가 자동 제공됩니다.
- 검색 FAQ: “깨진 건 신고 안 하셔도 됩니다. 새로 받으시면 예전 건 자동으로 없어집니다.”

**합성 `NAME_CHANGE-0083`**

- 질문: 미납 요금을 먼저 내고 명의변경하는 것과 명의변경 후에 내는 것 중 어느 쪽인가요?
- 답변: 먼저 완납해야 합니다. 미납 요금이 남아 있으면 명의변경이 진행되지 않습니다. 명의변경을 하면 기존 미납 요금이 자동으로 소멸됩니다.
- 검색 FAQ: “먼저 완납해야 합니다. 미납 요금이 남아 있으면 명의변경이 진행되지 않습니다.”

**합성 `COMPOUND-001`**

- 질문: 한도를 월 100만 원 이상으로 올릴 수 있나요 그리고 분실로 해지할 때 위약금 확인 절차를 알려주세요.
- 답변: 최대 월 100만 원까지만 가능합니다.
- 검색 FAQ 1: “최대 월 100만 원까지만 가능합니다.”
- 검색 FAQ 2: “약정 24개월 중 경과 개월을 확인해 12개월 미만이면 할인 반환금 100%, 12개월 이상이면 50%가 적용됩니다.”

**합성 `COMPOUND-022`**

- 질문: 개통한 지 두 달 됐는데 옮길 수 있나요 그리고 명의도용 신고 후 요금 취소까지 어떤 단계를 거치나요?
- 답변: 3개월이 지나야 옮기실 수 있어, 두 달째라면 아직 어렵습니다.
- 검색 FAQ 1: “3개월이 지나야 옮기실 수 있어, 두 달째라면 아직 어렵습니다.”
- 검색 FAQ 2: “접수 후 3영업일 이내에 조사가 진행되고, 조사에서 도용이 확인되면 해당 요금이 전액 취소됩니다.”

**합성 `BILLING-0100`**

- 질문: 요금이 너무 많이 나왔는데 25일까지 다 못 낼 것 같아요
- 답변: 관련 정보를 확인할 수 없어 고객센터에 문의해 주세요.
- 검색 FAQ: 없음. 평가셋의 필요한 답변에는 25일 납부 기한과 기한 조정 상담 안내가 있다.

**합성 `BILLING-0129`**

- 질문: 요금 두 번 냈는데 전화가 끊겼어요
- 답변: 정확한 정책을 확인하지 못해 안내를 보류하겠습니다.
- 검색 FAQ: “밀린 게 있으면 15일 지나서 끊깁니다. 두 번 낸 건 따로 접수하셔야 돌려드립니다.”

실제 채팅 `STORE`의 질문은 매장 찾기 요청이고, 저장된 답변은 매장 조회 기능이 아직 연결되지 않았다는 안내다. 검색 근거와 실제 매장 정보는 없다. 이 사례는 응답 문구가 적절한지와 별개로 **사용자의 매장 찾기 요구가 충족됐는지** 판단한다.
