# 2026-10-16 서비스 품질셋 v2.1, 서비스 데이터 근거와 코드 규칙 반영

> 이후 측정: 복합 질문 부분 질문과 추천 규칙 근거를 고친 뒤의 서비스 품질셋 v2.1 수치는 [2026-10-17 라벨 수정 후 재판정](../20261017-label-fixes/README.md)에 있다. 이 문서의 수치는 그 전 기준이다.

[v2 결합 측정](../20261016-v2-judge-ensemble/README.md)과 같은 답변 259턴을 바뀐 기준으로 다시 집계했다. 답변은 다시 만들지 않았다.

- 캡처: v2 캡처에 평가 DB의 실행 단계 기록과 요금제 표를 채우고(`backfill_capture_service_data.py`, 259턴 모두 질문 일치), 라벨을 v2.1로 바꿨다(`relabel_capture.py`).
- 근거: 요금제 답변 경로(planAnswer)를 탄 22턴에 요금제 표를 근거 `SERVICE:PLAN_TABLE`로 넣었다.
- 코드 규칙: 앱 고정 안내 문장은 근거성에서 빼고(`SERVICE_GUIDANCE`), 처리 실패 대체 문구는 실패로 보고(`SYSTEM_FALLBACK`), 회원 정보 질문에 비로그인 사용자가 받은 로그인 안내는 정상 처리로 본다(`LOGIN_GUIDANCE_ACCEPTED`).
- 재판정: 판정 입력(답변, 근거, 판정에 쓰는 라벨, 이전 턴)이 바뀐 27턴만 모델을 다시 불렀고, 232턴은 v2 판정을 재사용하면서 코드 규칙만 다시 적용했다(`run_bedrock_judge.py --prior`). 비용은 Qwen $0.07, DeepSeek $0.16, Mistral $0.16이다. 요금제 표가 들어가 요청이 길어졌다.

## 읽는 법

- 근거 없는 답이 크게 준 것은 판정 기준을 고친 결과다. 요금제 표와 같은 금액·데이터를 근거 없음으로 보던 판정과, 로그인 안내 문장을 근거 없는 사실로 보던 판정이 빠졌다. 서비스 답변이 좋아진 것이 아니다.
- 품질 통과율은 거의 그대로다. 요금제 답변의 상당수가 근거는 맞아도 질문에 맞지 않아(충족도) 여전히 실패이고, 대체 문구로 잘못 통과하던 보류·범위 밖 질문 4턴이 실패로 바뀌었다.
- 요금제 표를 근거로 받자 세 모델 모두 A048(최저가 요금제)과 U018(시니어 요금제 가격)을 통과로 판정했다. 남은 요금제 실패는 실제 답변 결함이다.
  - A047: 청소년·시니어를 빼 달라고 했는데 청소년·시니어 요금제만 나열했다.
  - U023, U030: 판매하지 않는 요금제를 묻자 없다고 하지 않고 다른 요금제를 안내했다.
  - A010, A012, A098: 요금 미납·요금제 변경 질문에 로그인 위약금 안내를 했다(요금제 질문 분류 오류).
- 모델끼리 갈리는 턴이 남아 있다. U026(넷플릭스 포함 요금제)에 5G 프리미엄 상세만 보여 준 답을 Qwen과 Mistral은 통과, DeepSeek는 실패로 봤다. 포함 여부를 말하지 않아 오해를 부르는 답이라 결합에서 실패가 맞다.
- 재사용한 232턴은 요금제 표 문장이 없는 이전 프롬프트로 판정했다. 이 턴들에는 서비스 데이터 근거가 없어 그 문장이 판정에 쓰이지 않는다.
- 판정은 한 번 실행한 값이다. 같은 모델을 다시 돌리면 최종 판정이 약 5% 바뀌므로(v2 결합 측정), 1~2%p 차이는 판단 근거가 아니다. 사람 판정은 없다.

## 파일

원시 파일은 `raw.tar.xz` 하나로 묶었다.

- `capture-v2_1.json`: 실행 단계 기록, 요금제 표, v2.1 라벨을 넣은 캡처(답변은 v2와 같다)
- `qwen.json`, `deepseek-v3.2-usw2.json`, `mistral-large-3.json`: 모델별 판정(지금 코드 규칙으로 다시 집계한 값)
- `combined-*.json`: 결합 판정과 턴별 모델 판정

```powershell
mkdir .measure/v2_1-service-data
tar -xf docs/chat-judge/results/20261016-v2_1-service-data/raw.tar.xz -C .measure/v2_1-service-data
python -X utf8 -m scripts.chat_judge.combine_judges .measure/v2_1-service-data/qwen.json .measure/v2_1-service-data/deepseek-v3.2-usw2.json --capture .measure/v2_1-service-data/capture-v2_1.json
```
