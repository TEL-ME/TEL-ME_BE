## 결합 (`combine_judges.py`, 하나라도 실패면 실패)

| 조합 | 품질 통과 | 근거 없는 답 | 미확정 |

| Qwen3 235B + DeepSeek V3.2 | 40.0% (100/250) | 40.2% | 9 |
| Qwen3 235B + Mistral Large 3 | 39.7% (96/242) | 45.6% | 17 |
| 세 모델 | 36.8% (91/247) | 48.3% | 12 |

| 묶음(Qwen3 235B + DeepSeek V3.2) | 품질 통과 | 근거 없는 답 |

| 고객 말투 단일 질문 | 31/113 | 25/69 |
| 복합 질문 | 1/20 | 6/9 |
| 멀티턴 | 15/39 | 4/23 |
| FAQ로 답할 수 없는 질문 | 39/60 | 12/15 |
| 통신과 가까운 범위 밖 질문 | 10/10 | 0/0 |
| 흐름 회귀 | 4/8 | 2/6 |

- 모델 하나만 쓰면 통과율이 46–49%로 비슷하지만, 결합하면 37–40%로 내려간다. 한 모델이 통과시킨 답을 다른 모델이 실패로 잡는 턴이 있어서다.
- [Judge 검증셋](../../README.md#평가셋) 116건에서 단일 Judge는 사람이 실패로 본 답을 15–21건 통과시켰고, Qwen3 235B + DeepSeek V3.2 결합은 10건이었다(최종 판정 일치 91·89 → 97/116, 판정자 A 기준). 그래서 결합 수치가 실제 품질에 더 가까울 가능성이 크다. 다만 서비스 품질셋에는 사람 판정이 없어 확인되지 않았다.
- FAQ로 답할 수 없는 질문에서 사실을 말한 답 15개 중 12개가 근거 없는 답이었다. 답을 찾지 못하면 대부분 보류하지만, 사실을 말하면 지어낸 경우가 많다.

## DeepSeek V3.2 리전

도쿄의 DeepSeek V3.2는 동시 호출을 늘리면 호출당 시간도 같이 늘어 처리량이 막힌다(같은 충족도 요청 16건 동시: 도쿄 36.1초, 오레곤 5.7초). 그래서 오레곤(`deepseek-v3.2-usw2`)으로 같은 259턴을 다시 판정했다.

| 리전 | 동시 호출 | 걸린 시간 | 호출 중앙값 | 비용 | 품질 통과 | Qwen3 235B와 결합 |
| --- | ---: | --- | --- | --- | --- | --- |
| 도쿄 | 6 | 35분 | 9.5초 | $0.94 | 46.2% (117/253) | 40.0% (100/250) |
| 오레곤 | 16 | 3분 | 1.7초 | $0.78 | 45.7% (117/256) | 38.9% (98/252) |

- 같은 모델인데 두 실행의 최종 통과·실패 판정은 259턴 중 246턴(95%)만 같다(근거성 252, 충족도 246, 보류 243). 모델끼리의 차이(90~93%)와 크게 다르지 않아, 결합 수치의 1~2%p 차이는 실행마다 바뀌는 범위 안이다.
- 판정 요청이 미국 리전으로 나간다. 내용은 FAQ 본문과 합성 질문이고 개인정보는 없다.

## 파일

원시 파일은 `raw.tar.xz` 하나로 묶었다(모델끼리 겹치는 요청 본문이 많아 묶어서 압축하면 1/10로 준다).

- `qwen.json`, `deepseek-v3.2.json`(도쿄), `deepseek-v3.2-usw2.json`(오레곤), `mistral-large-3.json`: 모델별 판정 원본(요청, 응답, 토큰, 집계)
- `combined-*.json`: 결합 판정과 턴별 모델 판정

```powershell
mkdir .measure/v2-judge-ensemble
tar -xf docs/chat-judge/results/20261016-v2-judge-ensemble/raw.tar.xz -C .measure/v2-judge-ensemble
python -X utf8 -m scripts.chat_judge.combine_judges .measure/v2-judge-ensemble/qwen.json .measure/v2-judge-ensemble/deepseek-v3.2-usw2.json
python -X utf8 -m scripts.chat_judge.run_bedrock_judge docs/chat-judge/results/20261016-v2-baseline/capture.json.gz --model deepseek-v3.2-usw2 --workers 16 --allow-bedrock-call --out <새 결과>
```
