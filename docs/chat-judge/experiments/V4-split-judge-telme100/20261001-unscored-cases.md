## 다음 검토 때 볼 점

- `grounding`의 원시 응답에서 `claims[].claim`이 실제 답변의 어느 구절을 인용하려 했는지 확인한다.
- `coverage`에서 `factChecks`의 순서와 각 `answerQuote`가 답변 원문과 일치하는지 확인한다.
- `abstentionSignals`에서 `evidenceQuotes[].quote`가 해당 `sourceId` FAQ의 실제 `answer`에 존재하는지 확인한다.
- 형식만 어긋난 사례와 모델이 사실을 잘못 이해한 사례를 구분한다. 검증을 느슨하게 해 미채점을 없애는 것은 별도 판단이 필요하다.
