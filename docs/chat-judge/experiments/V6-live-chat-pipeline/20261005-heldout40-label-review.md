# V6 별도 40건 사람 라벨 재확인 기록

아래 두 사례는 대조 과정에서 발견한 기준과 판정의 충돌 가능성을 확인해 사람 판정본에 반영했다. 원문 RAG 근거와 평가 기준에 맞춰 판정 이유 및 답변 불가 라벨을 정리했다.

## V6H-007: 제조사 서비스센터 안내의 근거성

- 답변: “침수된 단말은 수리 대상으로, 제조사의 서비스센터에서 점검 및 수리를 받으셔야 합니다.”
- 실제 전달 근거 `DEVICE-0088`: “침수 단말은 제조사 서비스센터 수리 대상입니다.”
- 반영: 근거성 `UNSUPPORTED`, 답변 불가 `SHOULD_ABSTAIN`은 유지했다. `DEVICE-0088`이 제조사 서비스센터 수리 안내를 뒷받침하므로 기존 이유를 바로잡고, 근거가 없는 부분은 “점검” 절차라고 좁혀 적었다.

## V6H-024: 근거성 및 답변 불가 라벨의 관계

- 답변: “남아 있는 할부금을 모두 정산하거나, 양수인인 본인이 신용 심사를 통과해야 합니다.”
- 실제 전달 근거 `NAME_CHANGE-0042`, `NAME_CHANGE-0018`: 양수인의 신용 심사 조건을 안내한다. 완납 선택지는 이 실행에서 전달되지 않았다.
- 반영: 근거성 `UNSUPPORTED`, 답변 불가 `SHOULD_ABSTAIN`으로 정리했다. 완납 선택지는 실제 전달 근거에 없으므로 이를 단정한 답변을 안전하게 전달할 수 없었다. 질문에 답할 근거가 있다는 `ENOUGH` 판정은 유지했다.

사람 판정본을 동일한 Judge 원시 결과와 다시 대조했다. 원시 결과를 바꾸거나 새 모델을 호출하지 않았다.
