# V6 별도 40건 사람 판정본

> 이 문서는 사람의 판정입니다. 질문, 참고 FAQ, 실제 저장 답변, 생성에 전달된 실제 RAG 근거를 대조해 작성했습니다.

판정자: 이용재

별도 파이프라인 실패 유형은 답변의 근거성·질문 충족도와 별개로 라우팅 및 응답 흐름 오류를 기록합니다. `MISROUTED_CLARIFICATION`은 질문과 무관한 의도로 잘못 분류해 엉뚱한 확인 질문을 한 경우입니다. V6H-026에 적용했습니다. V6H-012는 실제 검색 답변에 외국인 적용이 없어 근거 부족으로 갱신했고, V6H-024는 실제 검색에 포함되지 않은 완납 선택지를 답변이 덧붙인 근거성 문제로 분류했습니다.

원문 검토표의 질문, 답변, 실제 근거는 그대로 두고 빈 판정 칸을 아래 사람 판정으로 채웠습니다. 원본 블라인드 표는 별도 파일로 보존합니다.
