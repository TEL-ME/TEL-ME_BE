## 오류 유형과 우선순위

1. **놓치면 위험한 근거 밖 답변**: V6H-011의 만 18세 경계, V6H-029의 `기간 안`과 `기간 경과` 반전, V6H-038의 배송비 포함 추론을 우선 회귀 사례로 둔다. V6H-039는 근거성은 맞지만 근거 충분성을 잘못 판단한 짝 사례다.
2. **정상 답변을 잘못 막는 근거성 판정**: V6H-001, 002, 009, 013, 021에서 실제 근거를 빠뜨리거나 사용자 상황과 일반 권고를 FAQ 정책 주장으로 혼동했다. V6H-032, 033은 주장 추출 단계에서 보류 문구나 질문 되풀이를 사실 주장으로 뽑았다.
3. **질문 충족도 기준 위반**: V6H-003은 질문하지 않은 내용을 요구했다. V6H-031은 잘못된 서류를 부분 정답으로 인정했다. V6H-032, 033은 복합 질문의 답한 부분과 보류한 부분을 섞었다.
4. **근거 충분성 오판**: V6H-001, 007, 013, 015, 030은 답할 근거가 있는데 부족하다고 판단했다. V6H-038, 039는 배송비 근거가 없는데 충분하다고 판단했다.

최종 답변 불가 판정의 불일치 **11건은 모두 같은 턴의 근거성 불일치에서 파생**됐다. 현재 `decide_abstention()`은 근거성이 `UNSUPPORTED`면 `SHOULD_ABSTAIN`을 우선 적용한다. 따라서 이 11건을 답변 불가 판정 코드의 독립 오류로 세거나, 판정 순서만 바꿔 해결하려 해서는 안 된다.

## 다음 수정과 확인

- 주장 추출에서는 사용자 질문의 되풀이, 근거 부족 안내, 단순 권고를 사실 정책과 구별한다. 다만 `고객센터에서 신청해야 한다`처럼 절차를 안내하는 권고는 계속 검증한다. V6H-009, 012, 032, 033으로 두 경우를 함께 확인한다.
- 근거성 판정에서는 실제 전달 근거 **전체**, 연령 경계, `안`과 `경과` 같은 조건, 질문의 생략된 대상을 확인한다. V6H-001, 002, 011, 029, 038을 우선 회귀 사례로 둔다. `포함`처럼 답변만으로 대상이 불명확하면 임의로 배송비 무료라고 해석하거나 통과시키지 않고 검토 대상으로 남긴다.
- 근거 충분성은 답변을 참고하지 않고 **질문의 각 요구사항**을 근거로 충족할 수 있는지 검사한다. 재발급 비용과 배송비를 별개로 보고, 사용자가 제시한 현재 상태까지 FAQ가 증명해야 한다고 요구하지 않는다. V6H-030, 038, 039로 확인한다.
- 질문 충족도는 복합 질문의 각 하위 질문을 독립 채점한다. 근거가 없어 적절히 보류했더라도 해당 질문의 사실 답변은 `MISSED`로 남기고, 보류의 적절성은 별도 축에서 평가한다. V6H-031, 032, 033으로 확인한다.
- V6H-012의 적용 범위 판정을 확정했다. FAQ 질문 문구는 정책 근거로 삼지 않고, 실제 검색 답변에 없는 외국인 적용은 근거 부족으로 처리했다. 전체 FAQ의 `SUBSCRIBE-0108`은 실제 생성 입력에 없으므로 이 실행의 근거로 소급해 사용하지 않는다.

이 40건은 이제 개선에 참고한 표본이다. Judge를 고친 뒤에는 이 사례를 회귀 검증에 쓰고, 개선 수치는 별도 신규 사람 판정 표본으로 확인한다. 사람이 기록한 기존 판정본과 원시 Judge 결과는 이 분석에서 수정하지 않았다.
