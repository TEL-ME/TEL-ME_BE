# V6 채팅 파이프라인 판정표

## 문서 성격

이 파일은 블라인드 사람 검토표를 바탕으로 사람이 직접 판정했습니다. 판정에는 블라인드 표에 보이는 질문·기준 FAQ·실제 저장 답변·실제 RAG 근거만 사용했습니다.

표본은 고정 평가 질문으로 실행한 결과이며 실제 사용자 트래픽 표본은 아닙니다. 실제 RAG가 비어 있거나 부족한 경우, 기준 FAQ에 답이 있더라도 그것을 실제 파이프라인에 전달된 근거로 간주하지 않았습니다.

## 판정 기준

- 근거성은 답변의 사실 주장이 캡처된 실제 RAG 근거로 뒷받침되는지 봤습니다. 사실 주장이 없는 보류·범위 안내는 `NOT_APPLICABLE`입니다.
- 질문 충족도는 기준 FAQ의 사실을 답변이 어느 정도 다뤘는지 평가했습니다. 복합 질문은 하위 질문별로 판정했습니다.
- 답변 불가 판정은 실제 근거가 부족할 때 안전하게 보류했는지, 근거가 있는데 과하게 보류했는지, 근거 없는 내용을 답해 보류했어야 했는지를 기록했습니다.
- 근거 충분성은 모델에 실제 전달된 RAG만 기준으로 삼았습니다. 기준 FAQ가 있어도 캡처된 RAG에 없다면 근거 부족으로 표시하고 검색 누락을 메모했습니다.

---

## 독립 판정 집계

- 근거성: `SUPPORTED` 20건, `UNSUPPORTED` 8건, `NOT_APPLICABLE` 11건
- 답변 불가: `APPROPRIATE` 7건, `SHOULD_ABSTAIN` 8건, `OVER_REFUSAL` 4건, `NOT_APPLICABLE` 20건
- 실제 전달 근거 충분성: `ENOUGH` 23건, `INSUFFICIENT` 16건
