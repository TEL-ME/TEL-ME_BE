# V6 Judge 기준 수정 결과

## 수정 목적

사람 검토에서 확인한 기준을 Judge 입력과 판정 규칙에 반영했다. FAQ 질문 제목은 정책 근거가 아니며, FAQ 답변 본문과 실제로 확정된 상담 조건만 근거로 본다. 특히 FAQ 제목에만 있는 대상·조건을 답변 본문이 확인해 주지 않으면, 두 내용을 합쳐 정책을 추론하지 않는다.

## 반영한 변경

- 주장 추출에는 실제 AI 답변만 전달하고, 답변에 없는 주장을 만들어내지 않도록 지침을 보강했다.
- 근거성 판정은 FAQ 질문을 전달하지 않고 FAQ 답변 본문만 사용한다. 현재 질문과 이전 질문은 답변의 생략된 대상을 해석할 때만 제공한다.
- 근거 충분성 판정은 하위 질문별로 독립 평가한다. 근거 인용은 해당 FAQ 답변의 원문과 일치해야 한다.
- 성인 대상 규칙을 외국인 전체에 적용하는 것처럼, 근거에 없는 대상 간 적용 범위를 추론하지 않도록 했다.
- 답변 품질 판정도 FAQ 질문을 빼고 FAQ 답변 본문만 기준 자료로 사용한다.
- 인용문을 실제 FAQ 답변 또는 확정 조건에서 검증할 수 없으면 점수에 넣지 않고 미채점으로 남긴다.

## 실행과 결과

- 기존 실제 Spring 채팅 캡처 40건을 재사용했다. AI 답변 생성은 다시 하지 않았다.
- 평가 모델: vLLM 0.29.0, `Qwen/Qwen3-14B-AWQ`, 동시 요청 8개.
- 전체 40건의 실행을 마쳤고, 39건은 모든 축을 채점했다. 1건은 grounding 인용이 입력 근거와 일치하지 않아 안전하게 미채점 처리했다.
- V6H-012는 FAQ 질문 제목을 제외한 뒤 `UNSUPPORTED`, 답변 근거 `INSUFFICIENT`로 판정되어 사람 판정과 일치했다.
- Judge 및 파이프라인 평가 단위 테스트 53개가 통과했다.

| 평가 항목 | 기존 Judge 일치 | 수정 Judge 일치 | 비고 |
| --- | ---: | ---: | --- |
| 근거성 | 29/40 | 32/39, 1건 미채점 | 채점된 39건 중 32건 일치 |
| 답변 충실도 | 34/40 | 34/40 | 하위 질문 단위 38/44에서 38/44 일치 |
| 답변 근거 충분성 | 32/40 | 31/40 | FAQ 질문을 근거에서 제거한 뒤 더 엄격히 평가 |
| 답변 불가 판단 | 29/40 | 32/39, 1건 미채점 | 채점된 39건 중 32건 일치 |

수정 후 일치율은 이 40건 사람 검토표와의 비교일 뿐, 실제 서비스 전체의 정확도나 환각률을 보증하지 않는다. 근거 충분성 일치가 32건에서 31건으로 낮아진 점도 남아 있어, 이 기준을 확정하려면 해당 불일치 사례를 추가 검토해야 한다.
