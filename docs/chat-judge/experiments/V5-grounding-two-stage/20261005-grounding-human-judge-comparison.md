## 답변 주장 비교

사람 문서에는 65개 주장이 판정되어 있고 Judge는 67개 주장을 출력했습니다.

- 사람 주장의 63개는 Judge 주장과 문구가 일치했습니다.
- 이 63개는 `SUPPORTED`/`UNSUPPORTED` 판정과 근거 ID도 모두 일치했습니다.
- 나머지 두 사람 주장은 `H-012`와 `H-037`의 복합 문장입니다. Judge는 각 문장을 두 개의 더 작은 주장으로 나눴습니다. 나뉜 네 주장 모두 사람 판정과 같은 근거 ID로 `SUPPORTED`였습니다.
- 답변에 없는 문장을 claim으로 만들거나, 동일 문구 claim의 판정·근거 ID가 다른 사례는 확인되지 않았습니다.

따라서 이 표본에서는 claim의 세분화 방식 차이는 있었지만, 이를 근거로 확인한 사실 판단의 불일치는 없었습니다.

## 해석과 한계

이 결과는 고정된 합성 검증셋에서 선택한 40건의 근거성 Judge를 점검한 결과입니다. 실제 사용자가 입력한 질문, 실제 생성 답변, 실서비스 검색 근거를 평가하지 않았으며 표본도 무작위 단순 표본이 아닙니다. 이번 결과만으로 전체 Judge의 일반 정확도, 실제 채팅 환각률 또는 품질 개선 효과를 주장할 수 없습니다.

현재 확인 가능한 결론은 다음으로 한정합니다.

1. 사람 판정 40건에서 전체 판정은 모두 일치했습니다.
2. 비교 가능한 동일 claim 63건의 판정과 근거 ID가 모두 일치했습니다.
3. 두 건은 claim 분할 차이였고, 나뉜 하위 주장 판정은 사람 판정과 맞았습니다.
4. 다음 신뢰도 확인에는 실제 채팅 사례를 사전에 고정하고, Judge 결과를 보지 않은 사람이 답변과 실제 사용 근거를 독립 판정하는 표본이 필요합니다.
