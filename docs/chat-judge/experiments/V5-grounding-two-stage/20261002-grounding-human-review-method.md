# 근거성 Judge 사람 검토 표본

## 목적

근거성 Judge의 주장 추출과 FAQ 근거 판정을 확인하는 독립 표본이다. 기존 35건 미채점 사례는 제외했다. 사람 검토 자료에는 Judge 결과, 정답 라벨, 샘플링 유형을 넣지 않았다.

## 추출 기준

- 원본: 20261001-validation-v2-telme100-improved-raw.json.gz (500건)
- 원본 SHA-256: 3ebf2c2eba165140160538313a05e6b3c1fcabc650b6066243675d3805755341
- 기존 미채점 35건과 별도 vLLM 재실행 대상 35건을 모두 제외하고 judgeStatus=SCORED 항목에서 추출
- 고정 시드: 20261002
- 층화: SUPPORTED 10건, UNSUPPORTED_EXTRA 10건, NO_EVIDENCE 5건, OVER_REFUSAL 5건, COMPOUND_PARTIAL 10건
- 선정 항목을 다시 섞고 H-001부터 익명화
- 제외 후 표본 선정 가능 풀: 447건

## 사람 검토 방법

20261002-grounding-human-review-blind.json을 전달해 답변에서 사실 주장을 직접 추출하고, 각 주장을 FAQ 답변과 대조한다. 조건, 부정, 대상, 금액, 기간, 예외를 보존했는지 확인하고 각 claim의 근거 ID를 기록한다. 모호한 관계는 강제 판정하지 않고 NEEDS_HUMAN_REVIEW로 남긴다.

40건의 판정을 모두 잠근 뒤에만 20261002-grounding-human-review-key.json을 사용해 원본 결과와 비교한다. 키 파일에는 표본 유형과 원본 ID가 있으므로 블라인드 검토자에게 미리 공유하지 않는다. 일치율, 답변에 없는 claim 비율, 미판정 수는 이 표본에 대한 결과로만 보고하며 500건 전체 성능으로 일반화하지 않는다.

최종 중복 검사에서 vLLM 재실행 대상과 겹친 5건을 찾아 같은 층의 새 문항으로 교체했다. 현재 블라인드 파일은 재실행 대상 35건과 겹치지 않는다.

## 검토 상태

사람 판정과 Judge 비교를 완료했다. 결과는 [교차 검증 보고서](20261005-grounding-human-judge-comparison.md)에 기록했다. 40건 모두 전체 판정이 일치했다. 층화 표본의 결과이므로 500건 전체나 실제 서비스 품질로 일반화하지 않는다.
