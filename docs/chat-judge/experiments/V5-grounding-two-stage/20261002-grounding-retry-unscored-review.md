# vLLM 근거성 재시도 후 미채점 35건 검토

이 문서는 2026-10-02 vLLM 근거 인용 재시도 후에도 채점되지 않은 35건을 사람이 확인하기 위한 자료입니다. 각 항목에 질문, 실제 답변, 검색 FAQ, 최초 Judge의 주장·판정, 재시도 인용문과 평가셋 기대 라벨을 모았습니다.

> 재시도 인용문 검증은 모델이 고른 문구가 실제 답변에 연속된 원문 그대로 존재하는지만 확인합니다. 이 검증이 실패했다고 답변이 틀렸다는 뜻은 아닙니다. 반대로 인용문 검증을 통과해도 FAQ가 주장을 의미상 뒷받침하는지는 별도 판단입니다.

## 전체 요약

- 대상: 35건 (500개 케이스 중 근거성 판정 재시도에서 여전히 미채점)
- 사실 주장에 대응하는 인용문을 못 찾아 미채점: 30건
- 재시도 인용문이 답변 원문에 없어 미채점: 5건
- 아래의 ‘기대 근거성 라벨’은 평가셋에 기록된 기준 라벨입니다. 사람이 검토할 때 실제 답변 및 FAQ와 비교해 라벨 자체가 적절한지도 판단해 주세요.
