## 토큰 사용량

Bedrock 응답의 `usage` 필드를 합산했다. 구조화 출력의 재시도가 있었던 응답은 첫 응답과 재시도 응답을 모두 포함한다.

| 항목 | 사용량 |
| --- | ---: |
| 입력 토큰 | 1,526,407 |
| 출력 토큰 | 306,060 |
| 사용량이 기록된 응답 | 2,509 |

여기에는 509건 본 실행과 검증 실패 9건의 재시도가 포함된다. 별도 사전 연결 확인, 이 실행 전의 Qwen 파일럿, Sonnet 및 Luna 접근 확인은 합산하지 않았다. 따라서 AWS 계정의 전체 Bedrock 사용량이나 청구액과 같지 않다.

## 공개 요금표 기준 추정

AWS Bedrock 요금 페이지에서 확인되는 Qwen3 235B A22B 2507 Standard 요금은 입력 100만 토큰당 0.2266 USD, 출력 100만 토큰당 0.9064 USD다. 이 요금으로 계산한 이번 Qwen 실행의 참고 추정액은 다음과 같다.

```text
1,526,407 / 1,000,000 × 0.2266
+ 306,060 / 1,000,000 × 0.9064
= 약 0.6233 USD
```

AWS 요금표의 해당 가격 행은 Asia Pacific (Sydney) 표에 표시되어 있다. 실제 호출은 Tokyo 리전에서 했으므로 **0.6233 USD는 Tokyo 청구액 확정치가 아닌 공개 요금표 기반 참고치**다. AWS 청구 내역에서 실제 금액을 확인해야 한다. [AWS Bedrock 요금표](https://aws.amazon.com/bedrock/pricing/)

같은 입력량과 출력량으로 세 모델을 모두 실행한다고 단순 가정하면 참고 추정액은 약 1.87 USD다. 모델별 출력 길이, 실패 재시도, 리전별 요금이 달라질 수 있어 예산 확정값으로 쓰면 안 된다. Sonnet과 Luna 실행은 별도 사용자 지시가 있을 때 진행한다.
