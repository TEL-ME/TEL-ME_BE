# V7 세 모델 검토 목록 1차 판정

대상: [세 모델 교차 검증 사람 검토 목록](v7-sonnet-4-6-human-review.md)

## 판정 원칙

- GPT-OSS, Qwen, Sonnet의 다수결을 정답으로 간주하지 않는다.
- 답변의 사실 주장은 실제 검색 FAQ 답변으로 대조한다. 질문과 FAQ 질문 문구는 정책 근거로 인정하지 않는다.
- 답변 충실도, 검색 근거 충분성, 답변 보류는 서로 다른 판단으로 본다.
- 아래 결과는 자동 규칙과 기존에 기록된 사람 판정을 이용한 1차 판정이다. 목록 302건 전부를 독립적인 사람 정답 라벨로 확정한 결과가 아니다.

## 기준만으로 정리할 수 있는 반복 불일치

### 검색 결과가 비었는데 GPT-OSS가 `UNCERTAIN`으로 판정한 90건

90건 모두 검색 근거가 없고 답변은 거절형이다. Qwen과 Sonnet은 `INSUFFICIENT` 및 `APPROPRIATE`로 판정했지만 GPT-OSS는 `UNCERTAIN` 및 `REVIEW`로 판정했다.

V7 기준에는 근거가 비어 있으면 `INSUFFICIENT`, 거절 답변의 최종 판정은 `APPROPRIATE`라고 명시돼 있다. 이 90건은 GPT-OSS의 판정이 기준에서 벗어난 것으로 본다. 검색 근거가 없다는 이유만으로 불확실 판정할 사안은 아니다.

### 범위 밖 질문에 거절했는데 GPT-OSS가 답변 충실도를 다르게 판정한 21건

21건 모두 기대 동작이 `OUT_OF_SCOPE`이고 실제 답변도 통신 범위 밖이라고 안내하는 거절이다. Qwen과 Sonnet은 `NOT_APPLICABLE`로, GPT-OSS는 `MISSED` 19건 또는 `COMPLETE` 2건으로 판정했다.

답변 충실도 기준은 서비스 범위 밖 요청에 대한 거절을 `NOT_APPLICABLE`로 둔다. 따라서 이 축에서는 Qwen·Sonnet 판정이 기준에 맞고 GPT-OSS 판정은 맞지 않는다.

두 묶음은 18건이 겹친다. 합쳐서 93개의 답변에 해당하지만, 한 답변의 다른 판정 축까지 해결했다는 뜻은 아니다.

## 기존 사람 판정 자료와 대조

기존에 사람이 판정한 40건 가운데 GPT-OSS만 다른 의견을 낸 축별 22건을 대조했다. GPT-OSS 판정은 22건 모두 기록된 사람 판정과 달랐고, Qwen·Sonnet의 합의는 21건에서 사람 판정과 같았다. 근거성의 나머지 1건은 세 모델 모두 사람 판정과 달랐다.

이 40건은 기존 회귀 자료이지 무작위 표본이 아니므로, 이 결과를 전체 데이터에서의 정확도나 GPT-OSS 일반 성능으로 확대하지 않는다.

## 남은 범위

위의 명시적 기준 위반과 예시 대조만으로 검토 목록 전체가 해결되지는 않는다. 특히 실제 근거가 있는 답변의 의미상 일치 여부, 조건·대상·예외의 누락, 복합 질문의 일부 답변 충족도는 사례별 확인이 필요하다. 나머지 항목에는 모델 다수결을 임시 판정으로 붙이지 않았다.

따라서 이 문서는 302건 전체의 최종 골드 라벨이 아니다. 기준을 적용해 자동으로 좁힐 수 있는 불일치와 실제 FAQ 근거를 본 예시를 정리한 1차 판정이다.
