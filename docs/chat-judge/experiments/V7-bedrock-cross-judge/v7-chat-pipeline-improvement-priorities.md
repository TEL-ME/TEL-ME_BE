# V7 채팅 파이프라인 개선 우선순위

## 결론

우선 손볼 부분은 근거 없는 숫자와 조건을 사용자에게 보내지 않는 것, 정답 FAQ 검색 누락을 줄이는 것, 실패한 실행을 안전하게 끝내는 것이다. 그 다음 라우팅 오류와 복합 질문의 부분 답변 처리를 보완한다.

## 우선순위

| 순위 | 개선 영역 | 근거와 현재 상태 | 해야 할 일 |
| ---: | --- | --- | --- |
| 1 | 근거 없는 주장 차단 | V6 실행 실패 15건 중 13건은 `LLM502-1`이다. 생성 기록에 FAQ 근거가 없는 금액이나 수치가 남았다. V7 사람 검토에서도 만 18세 경계 조건을 뒤집은 답변과 3영업일 조건을 반대로 안내한 답변이 확인됐다. 세 Judge 모두 이 두 사례를 놓쳤다. | 금액, 수치, 나이, 기간, 부정, 예외 조건을 FAQ와 대조한다. 검증에 실패한 문장은 저장하거나 SSE로 보내지 않는다. 문장 전체를 안전한 안내로 바꾸거나 해당 하위 질문만 보류한다. |
| 2 | 정답 FAQ 검색 누락 감소 | 답변 가능한 하위 질문의 정답 FAQ 묶음 507개 중 123개를 놓쳤다. 검색 후보와 실제 RAG 입력의 적중은 각각 384/507, 75.74%였고, 저장된 근거는 369/507, 72.78%였다. 누락은 99개 질문에서 발생했다. | 라우팅과 질문 재작성, 후보 검색, 최종 검색 결과, 프롬프트 전달, 답변 근거 저장을 단계별로 확인한다. 원문 검색과 정제 질문 검색을 같은 평가셋으로 비교하고, 복합 질문은 하위 질문별로 정답 근거가 전달되는지 확인한다. |
| 3 | 실패 실행의 종료와 복구 | 509건 중 15건은 최종 답변이 없었다. 13건은 `LLM502-1`, 2건은 스트림 중단 `LLM502-2`였다. 모두 단순 LLM 연결 장애로 취급하면 원인을 놓친다. | 근거 검증 실패와 스트림 중단을 별도 원인으로 기록한다. 실패 시 실행 상태를 종료 상태로 확정하고, 잘못된 답변이 남지 않게 한다. 안전한 재시도나 보류 안내가 가능한지 확인한다. |
| 4 | 의도 분류와 확인 질문 | V6 평가에서 기대 intent와 다른 라우팅이 39건 관찰됐다. 자동 비교 신호이므로 39건 모두 실제 오분류라고 단정할 수는 없다. 다만 V7에서 로밍 신청 경로를 물은 사용자에게 매장 위치를 되묻는 `MISROUTED_CLARIFICATION` 사례가 사람 판정으로 확인됐다. 충분한 근거가 있는데 거절한 것으로 분류된 사례도 12건 있었다. | 실제 오분류와 단순 라벨 차이를 사례별로 나눈다. 부족한 조건이 있을 때만 관련 확인 질문을 하고, 다른 도메인의 질문으로 잘못 연결하지 않는지 검사한다. 답변 가능한 근거를 찾았는데 거절하는 경우도 별도 회귀 사례로 둔다. |
| 5 | 복합 질문의 부분 답변 | V7에서 복합 질문 46건은 사람은 답변 전체를 하나로 판정하고 Judge는 하위 질문별로 판정해 충실도 직접 비교에서 제외됐다. 사람 검토상 한 하위 질문은 맞게 답하고 다른 질문은 보류한 사례는 `PARTIAL`과 `APPROPRIATE`가 맞았다. 반면 전달된 FAQ에 없는 유심 재발급 서류를 만들어 답한 사례도 있었다. | 하위 질문별로 검색과 근거 검증을 한다. 근거가 있는 부분은 답하고 없는 부분만 보류한다. 답변 일부의 근거 부족이 다른 부분의 정답을 훼손하지 않는지, 전체 응답이 완전 답변으로 잘못 표시되지 않는지 확인한다. |

## 검증할 때 볼 지표

- **근거 검색**: 하위 질문별 정답 FAQ 적중률, 실제 프롬프트에 전달된 근거 비율, 답변에 연결해 저장한 근거 비율
- **답변 안전성**: 금액과 조건 관련 근거 없는 주장 수, 상충 조건 수, 검증에서 차단된 뒤 사용자에게 잘못 노출된 답변 수
- **요청 처리**: 실행 실패율, `LLM502-1`과 `LLM502-2` 건수, 재시도 후 완료율, 실패 뒤 실행 상태의 일관성
- **라우팅과 충실도**: 실제 오분류, 잘못된 확인 질문, 충분한 근거가 있는데 보류한 경우, 하위 질문별 `COMPLETE`, `PARTIAL`, `MISSED`
- **응답 성능**: 전체 지연시간과 P95. 품질 개선 전후에는 같은 질문과 같은 데이터로 비교한다.

## 평가 결과를 해석할 때 주의할 점

V7 사람 검토 302건은 모델 간 불일치, 미채점, 과거 사람 판정과의 차이를 중심으로 선택됐다. 무작위 표본이 아니므로 이 결과를 전체 서비스의 환각률이나 정확도로 보면 안 된다. 302건 중 사람 판정은 `UNSUPPORTED` 54건, `PARTIAL` 63건, `MISSED` 77건이지만 이 분포 역시 선택된 검토 목록의 결과다.

세 모델이 모두 같은데 사람 판정과 다른 사례도 31건 있었다. `PIPE-DEVICE-0117`에서는 세 모델이 근거 있는 답변을 근거 부족으로 판단했고, `PIPE-SUBSCRIBE-0066`에서는 만 18세 조건을 뒤집은 답변을 세 모델 모두 놓쳤다. 모델 합의만으로 답변을 자동 승인하지 말고, 검증된 사례를 회귀 테스트로 유지해야 한다.

생성된 답변 494건 중 192건은 아직 사람 검토가 없다. 전체 품질이나 환각률을 산출하려면 이 답변도 같은 기준으로 검토해야 하며, 답변이 없었던 실행 실패 15건은 별도 서비스 실패율로 집계해야 한다.
